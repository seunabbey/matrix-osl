# Matrix OSL

A responsive, single-page company website for the Matrix Oilfield Services
Limited hiring assessment.

## Run

Open `index.html` in a modern browser. The page uses plain HTML, CSS and
JavaScript; it has no build step, backend, or runtime dependencies.

## Notes

- `WIREFRAME.md` describes the content hierarchy and responsive page plan.
- The five service lines, five core values, certifications, HSE statements and
  contact information follow the supplied company profile.
- Photography is loaded from Unsplash with responsive sizing parameters and
  descriptive alternative text. An internet connection is needed to display it.
- The contact form validates in the browser and displays a confirmation. It
  does not send or store submissions; connect an approved service before
  collecting enquiries.
- Light theme is the default; the selected theme is saved in browser storage.
